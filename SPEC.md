# Задача для Claude Code: бот-уведомлялка о слотах BLS Portugal (Санкт-Петербург)

## Цель
Локальный скрипт, который следит за появлением свободных слотов на подачу
визы в Португалию в BLS (Санкт-Петербург) и присылает уведомление в Telegram.
Записываюсь я сам, вручную. Бот ничего не бронирует.

## Жёсткие ограничения (не обсуждаются)
- НЕ бронировать слоты, НЕ нажимать submit/confirm на форме записи.
- НЕ обходить и НЕ решать капчу. Если встретилась капча или блок, остановить
  опрос и прислать мне сообщение «нужно вмешательство».
- Один аккаунт, без прокси, без ротации сессий.
- Без частых запросов: интервал 10–15 минут со случайным разбросом (jitter),
  при ответе 429/403 экспоненциальная пауза и уведомление.
- Логин и пароль не хранить в коде, токены только в `.env`.

## Стек
TypeScript + Playwright (Node 20+). Конфиг в `config.yaml`, секреты в `.env`.

## Как работает
1. Playwright с постоянным профилем (`launchPersistentContext`, `userDataDir`),
   запуск в видимом режиме. Я один раз вручную вхожу в личный кабинет
   (капчу прохожу сам), дальше скрипт использует эту сессию.
2. Опрос: открыть страницу записи, выбрать центр «Санкт-Петербург» и цель
   «Посещение друзей/родственников» (тип визы C), прочитать состояние
   календаря/списка дат. Ничего не нажимать дальше выбора фильтров.
3. Состояние сохранять в `state.json`. Уведомлять только при ИЗМЕНЕНИИ
   «нет слотов» → «есть слоты» (и обратно «слоты закончились»).
4. Сообщение в Telegram: что найдено (даты, время, если видно), прямая
   ссылка на страницу записи, время обнаружения.
5. Окно работы по умолчанию: с 17-го по 28-е число месяца, 08:00–22:00
   по Лиссабону (настраивается). Вне окна скрипт спит.
6. Если сессия истекла (редирект на логин): отправить «войдите заново» и
   ждать, не долбить сайт.
7. Раз в сутки сообщение «жив, слотов нет» (heartbeat), чтобы я знал,
   что бот работает, а не молчит из-за поломки.
8. Команда `/status` в боте: последнее время успешной проверки и результат.

## Первый шаг (обязательный)
Селекторов страницы у нас нет. Прежде чем писать парсер:
- открой страницу записи вместе со мной (я вхожу сам), изучи вёрстку;
- сохрани HTML-снимки состояний «слотов нет» и (когда появятся) «слоты есть»
  в `fixtures/`;
- вынеси селекторы в `config.yaml`;
- напиши парсер и юнит-тесты на этих снимках.
Пока нет снимка состояния «слоты есть», детектируй слоты по признаку
«исчез текст «нет слотов» / появились активные даты» и явно пометь это
как непроверенное предположение.

## Уточнения
- **Третье состояние «не распознано».** «Слоты есть» ставить, только когда
  видны активные даты. Если пропал текст «нет слотов», а активных дат нет
  (сменилась вёрстка, ошибка, пустая страница, не выбрались фильтры), это
  состояние `unknown`. Бот присылает скриншот и сохраняет HTML в
  `fixtures/unknown-*`, не чаще раза в час. Иначе одна правка вёрстки даст
  ложную тревогу или, наоборот, бот будет молча считать, что слотов нет.
- **Повтор при «слоты есть».** Если слоты держатся, а записаться я ещё не
  успел, напоминать не чаще раза в 20 минут, пока статус не сменится.
- **`/status` и команды.** Отвечать только на сообщения из
  `TELEGRAM_CHAT_ID`, остальные игнорировать. Читать только свой бот
  (`getUpdates`), никаких чатов и каналов.
- **Heartbeat** приходит и вне окна работы, с пометкой «вне окна».
- **Капча и 403** считаются блокировкой: одно сообщение «нужно
  вмешательство», и опрос стоит до ручного `npm run login`.
- **Часовой пояс окна.** Проверить, в какое время по Лиссабону реально
  открываются слоты. Если их выкладывают ночью, окно 08:00–22:00 их пропустит.
- **Сон Mac.** В README предупредить: если Mac засыпает, бот молчит
  (`caffeinate -s` или настройки энергосбережения). Такой сбой заметен
  по пропавшему heartbeat.
- **Тестовое уведомление.** Команда `npm run check -- --notify` делает один
  проход и отправляет результат в Telegram, чтобы проверить связку.

## Приёмка
- `npm run check` делает один проход и печатает результат без Telegram.
- `npm start` запускает цикл по расписанию.
- Тесты парсера зелёные на снимках.
- README: как получить токен бота (@BotFather), chat id, как запускать,
  как перелогиниться.

## Вне рамок
Автозапись, обход капчи, несколько аккаунтов, прокси, продажа/передача
слотов.
